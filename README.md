## 📌 Project Overview
This project was completed as part of my **MIT - PE Applied Data Science Program: Leveraging AI for Effective Decision-Making** curriculum. 


Hired as a Data Scientist for a food aggregator platform, I analyzed historical customer order data to identify demand trends across different restaurants. The primary objective was to extract actionable insights that would help the company enhance customer experience, optimize restaurant partnerships, and improve operational efficiency based on real ordering patterns.
